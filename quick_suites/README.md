# AWS Quick 服務總覽與自動化工具比較 — 簡報套件

本套件把這次 session 討論的內容（Amazon Quick Suite 六大服務、Quick Automate / Quick Flows / Step Functions 三方比較）整理成一份可直接簡報、也可分享瀏覽的 14 頁投影片，共三個檔案，內容互相對應、來源同一份資料（`slides_data.py`），確保不會顧此失彼。

## 檔案清單

| 檔案 | 用途 | 使用對象 |
|---|---|---|
| `AWS_Quick_Suites.pptx` | 可編輯的本機 PowerPoint 檔，14 頁、16:9，深色主題＋橘色重點色 | 要親自上台簡報、或需要再修改內容/版面的人 |
| `index.html` | 響應式網頁投影片播放版：單頁顯示、上一頁/下一頁、全螢幕、鍵盤與觸控換頁，桌機與手機都能開 | 不方便開 PowerPoint、想用瀏覽器快速回顧或分享連結／檔案給別人看的人 |
| `README.md`（本檔案） | 說明檔案清單與使用方式 | 所有人 |

> 若你之前收到的 `LLM需求對照表_修正版.xlsx`（已修正 5 項正確性問題的 Excel 檔）還在同一個對話輸出區，那是另一份獨立的資料健檢交付物，本簡報套件不再涵蓋那段內容（依你的要求已移除 Part 4）。

## 投影片內容大綱（14 頁）

1. 封面
2. 議程
3. Amazon Quick Suite 背景（2026 品牌重整）
4. 六大服務一覽
5–6. 各服務適用情境與成功案例（分兩頁）
7–8. 各服務使用限制（分兩頁）
9–12. Quick Automate vs. Quick Flows vs. Step Functions 四維度比較（主要目的／最佳情境／限制／不適合情況）
13. 三者定位一句話總結
14. 重點回顧

## 建議使用順序

- **要簡報／要改內容**：直接打開 `.pptx`，用 PowerPoint／Keynote／Google Slides 編輯或播放。
- **要快速瀏覽／要傳給別人看**：直接打開 `.html`（雙擊或拖進瀏覽器），支援方向鍵、空白鍵、PageUp/PageDown 換頁，右上角可全螢幕、可用下拉選單跳頁；手機直向瀏覽時投影片會維持 16:9 比例置中顯示（屬正常的信封效果，橫向或平板會更完整）。
- **要分享連結給團隊**：`.html` 是單一自包含檔案（不含外部依賴），可直接當附件寄出或放進共用資料夾，收件人不需要安裝任何軟體。
